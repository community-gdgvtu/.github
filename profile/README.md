## 👋 Who We Are

**GDG VTU** is the official Google Developer Group chapter at **Visvesvaraya Technological University**, one of the largest technical universities in India. We are a community-driven, student-led tech group that brings together developers, designers, and innovators to learn, build, and grow with Google technologies.

Whether you're writing your first line of code or shipping production apps — there's a place for you here.

## 🤝 Contributing

We welcome contributions from everyone — beginner or expert!

```bash
# 1. Fork the repository you want to contribute to
# 2. Clone your fork
git clone https://github.com/<your-username>/<repo-name>.git

# 3. Create a feature branch
git checkout -b feature/your-feature-name

# 4. Make your changes and commit
git add .
git commit -m "feat: describe your change"

# 5. Push and open a Pull Request
git push origin feature/your-feature-name
```

Please read our [**Contributing Guidelines**](./CONTRIBUTING.md) and follow our [**Code of Conduct**](./CODE_OF_CONDUCT.md) before submitting.
